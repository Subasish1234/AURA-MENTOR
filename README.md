# AURA

Adaptive University & Research Assistant

## Vision

AURA is a personalized AI companion designed to help students throughout their academic and professional journey.

Unlike traditional chatbots, AURA adapts its personality, remembers student progress, recommends learning paths, and provides academic and career guidance.

## Planned Features

* Personalized AI personalities
* Long-term memory
* Document-based RAG
* Recommendation engine
* Multi-agent workflows
* Knowledge graph
* Voice AI
* Image generation
* Video generation
* MCP integrations
